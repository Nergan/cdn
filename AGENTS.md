# cdn — инструкции для AI-агентов

Статические файлы, которые сайты берут с `https://cdn.jsdelivr.net/gh/Nergan/cdn@main/`. Cutaway ссылается на пути вида `cdn@main/<проект>/favicon.png` и на другие файлы этого репозитория. Переименование или удаление уже опубликованного пути ломает эти страницы. Новый файл клади рядом, старый путь оставь, пока ссылки не переведены.

## Опыт

Если по ходу задачи стало ясно то, что в следующий раз сэкономит неверный ход, допиши это в этот `AGENTS.md`. Ход работы и разовую ошибку не копируй. Неверную старую строку поправь, а не оставляй вторую рядом.


## Скиллы

Перед правкой открой https://github.com/DietrichGebert/ponytail/blob/main/skills/ponytail/SKILL.md.

## Правила

- Секреты не хранить и не коммитить. Репозиторий их не использует.
- Коммит и пуш — только когда владелец прямо просит. Push в `main` зеркалится на GitLab.
- `donate-widget.js` вставляют чужие страницы. Не ломай его глобальный контракт ради одной страницы.
